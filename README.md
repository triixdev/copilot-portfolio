# Portfolio Website (built with GitHub Copilot)

A responsive personal portfolio website built with HTML, CSS and JavaScript, generated and refined with GitHub Copilot Chat in a GitHub Codespace.

**Live site:** https://triixdev.github.io/copilot-portfolio/

![Portfolio screenshot](screenshot.png)

## Features
- Hero, About, Projects, Skills and Contact sections
- Dark/light theme toggle that remembers your choice
- Maroon and beige colour palette
- Original inline SVG illustrations (no stock photos)
- Fully responsive layout
- Hosted on GitHub Pages

## Tech used
HTML, CSS, JavaScript, GitHub Copilot, GitHub Codespaces, GitHub Pages

## How I used GitHub Copilot
1. Prompted Copilot Chat to generate a three-file portfolio (`index.html`, `style.css`, `script.js`).
2. Gave it my real project details so it replaced the placeholder content.
3. Asked it to restyle the site with a maroon and beige palette and replace the stock photos with custom SVG illustrations.
4. Reviewed the code, tested it with Live Server and deployed it with GitHub Pages.

## Run locally
Open `index.html` in a browser, or use the Live Server extension in VS Code.
